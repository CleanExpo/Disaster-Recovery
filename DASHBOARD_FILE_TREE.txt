DATA FLOW
=========

1. User visits /dashboard/admin/competitors
   ↓
2. Dashboard page loads with SWR hooks
   ↓
3. SWR fetches from API routes
   │
   ├── /api/competitor-analysis/overview
   ├── /api/competitor-analysis/competitors
   ├── /api/competitor-analysis/opportunities
   └── /api/competitor-analysis/keywords
   ↓
4. API routes query Prisma
   ↓
5. Prisma queries PostgreSQL
   ↓
6. Data returns through chain
   ↓
7. SWR caches data (60s)
   ↓
8. Components render with data
   ↓
9. User interacts with dashboard
   │
   ├── Sort/Filter → Local state update
   ├── View SWOT → Fetch SWOT data
   ├── Analyze → POST to /api/.../analyze/[id]
   └── Tab switch → Show cached data
