## 🔄 VIDEO EXTENSION CAPABILITY

### Create Longer Videos:
Veo 3.1 can chain 8-second clips into longer sequences:

**Example**: 24-second Residential Flood Response
1. **Clip 1** (0-8s): Emergency team arrives, begins assessment
2. **Clip 2** (8-16s): Water extraction equipment deployed
3. **Clip 3** (16-24s): Restoration complete, dry basement

**How to Generate**:
```javascript
// Generate first clip
const clip1 = await generateVideo(prompt1, 'clip1.mp4');

// Extend to clip 2
const clip2 = await geminiVideoService.extendVideo(
  'clip1.mp4',
  'Water extraction in progress, equipment operational'
);

// Extend to clip 3
const clip3 = await geminiVideoService.extendVideo(
  'clip2.mp4',
  'Restoration complete, basement dry, equipment being packed up'
);

// Result: 24-second sequence
```

## 🎨 PROMPT ENGINEERING PRINCIPLES

### What Makes Good Prompts:

#### DO Include:
- ✅ Specific scene description (location, setting, subjects)
- ✅ Camera technical details (lens, aperture, style)
- ✅ Lighting description (natural, professional, specific sources)
- ✅ Mood and aesthetic (professional, serious, trustworthy)
- ✅ Composition details (foreground, midground, background)
- ✅ Specific avoidances (no people, no text, no logos)

#### DON'T Include:
- ❌ Vague requests ("nice image of flood")
- ❌ Copyrighted content references
- ❌ People's faces (privacy/licensing issues)
- ❌ Text or logos (licensing problems)
- ❌ Multiple unrelated concepts
- ❌ Unrealistic requests

---

### Example Prompt Structure:

```
SCENE: [What you want to see - be specific]

DETAILS:
- [Specific element 1]
- [Specific element 2]
- [Specific element 3]
- [Setting and context]
- [Style and aesthetic]

CAMERA: [Lens mm] lens, f/[aperture], [photography style]
LIGHTING: [Natural/professional/specific description]
MOOD: [Emotional tone and professional context]
AVOID: [Specific things to NOT include]
```

## 🔧 TECHNICAL IMPLEMENTATION

### Generate Custom Image:

```javascript
const { GoogleGenerativeAI } = require('@google/generative-ai');

const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);

const model = genAI.getGenerativeModel({
  model: 'gemini-3-pro-image-preview' // Nano Banana Pro
});

const result = await model.generateContent('Your detailed prompt here');

// Extract image
for (const part of result.response.candidates[0].content.parts) {
  if (part.inlineData) {
    const buffer = Buffer.from(part.inlineData.data, 'base64');
    fs.writeFileSync('output.jpg', buffer);
  }
}
```

---

### Generate Custom Video:

```javascript
const videoModel = genAI.getGenerativeModel({
```
