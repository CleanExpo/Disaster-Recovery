## Component Breakdown

### Header (Fixed, 80px height)
- **Position**: Fixed top, z-index 50
- **Background**: White with 80% opacity + backdrop blur
- **Layout**: Flex, space-between
- **Left**: Logo (NRPG with "N" icon)
- **Center**: 3 MegaMenus (Services, Sectors, Locations) + Contractor Portal
- **Right**: Emergency number (XL+ only) + Emergency Button + Mobile toggle

### Hero (Grid 6/6)
- **Layout**: CSS Grid, 12 columns total
- **Left (6 cols)**: Text content, CTA, badges
- **Right (6 cols)**: HeroCarousel with HUD overlay
- **Height**: Auto (based on content, ~600-800px typical)

### The 1300 Blueprint
- **Layout**: 3-column grid (responsive: 1 col mobile, 3 cols desktop)
- **Background**: White (contrast with hero)
- **Numbers**: 7xl-8xl font size, blue color
- **Spacing**: py-24 (6rem vertical padding)

### Service Pillars
- **Layout**: 4-column grid (responsive: 1→2→4 cols)
- **Card Height**: 440px fixed
- **Card Width**: Auto (fills grid column)
- **Border Radius**: 2.5rem (40px)
- **Hover**: Translate-y -8px, shadow increase

### Client Sectors
- **Layout**: 4-column grid (responsive: 1→2→4 cols)
- **Background**: Slate-50 (light gray)
- **Card Padding**: 2rem (8)
- **Border Radius**: 1.5rem (24px)
- **Hover**: Translate-y -8px, shadow, arrow appears

### Final CTA
- **Layout**: Single column, centered text
- **Background**: Gradient blue-600 to blue-700
- **Border Radius**: 3rem (48px)
- **Padding**: 3-5rem (responsive)
- **Button**: Red, XL size, white text

### Footer
- **Layout**: 5-column grid (2 cols brand + 3 cols links)
- **Background**: Slate-950 (deep dark #020617)
- **Text Color**: Slate-400 (light gray)
- **Spacing**: py-16 (4rem vertical padding)

## Interactive States

### Hover Effects
```
Pillar Cards:
  • Image scale: 1 → 1.1 (zoom in)
  • Shadow: lg → 2xl + blue glow
  • Transform: translateY(0) → translateY(-8px)
  • Arrow: opacity-0 → opacity-100

Sector Cards:
  • Shadow: none → 2xl + blue glow
  • Transform: translateY(0) → translateY(-8px)
  • Arrow: opacity-0 → opacity-100

Buttons:
  • Background: Blue-600 → Blue-700
  • Shadow: lg → xl
  • Scale: 1 → 0.95 (active state)

Links:
  • Color: Slate-700 → Blue-600
  • Text decoration: none → underline (optional)
```

### Focus States
```
All interactive elements:
  • Outline: 2px ring, blue-500 color
  • Offset: 2px
  • Border radius: Inherited from element
```

### Active States
```
Buttons:
  • Scale: 0.95 (pressed down effect)
  • Shadow: Reduced
  • Duration: 100ms (quick response)
```

## Animation Timing

### Transitions
- **Fast**: 150ms (button hover, focus states)
- **Normal**: 300ms (card hover, menu open/close)
- **Slow**: 500ms (pillar card hover, carousel fade)
- **Carousel**: 700ms (image opacity transitions)

### Animations
- **Scanning Beam**: 3s infinite (ease-in-out)
- **Shimmer**: 2s infinite (loading state)
- **Pulse**: 1s infinite (emergency button indicator)

### Keyboard Navigation
- **Tab**: Navigate through interactive elements
- **Enter/Space**: Activate buttons/links
- **Escape**: Close mega menus
- **Arrow Keys**: Navigate carousel slides

### ARIA Labels
- All buttons have descriptive labels
- All images have alt text
- All links have meaningful text (no "Click here")
- Form inputs have associated labels

### Color Contrast
- **Text on White**: Slate-900 (21:1 ratio) ✅
- **Text on Blue**: White (4.5:1+ ratio) ✅
- **Text on Dark**: Slate-400 (7:1+ ratio) ✅
- **Links on White**: Blue-600 (4.5:1+ ratio) ✅
