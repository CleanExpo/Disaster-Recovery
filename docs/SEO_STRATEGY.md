## Technical SEO

### Site Structure

**URL Hierarchy:**
```
/                                    # Homepage
/[service]/                          # Service overview page
/[city]/[service]/                   # Location-specific service
/resources/[disaster-type]/[slug]    # Blog posts
/guides/[slug]                       # Long-form guides
/contractors                         # NRPG acquisition
/claim                              # Claim intake wizard
```

**Example URLs:**
```
/water-damage                        # National water damage page
/sydney/water-damage                 # Sydney water damage
/melbourne/fire-restoration          # Melbourne fire restoration
/resources/water-damage/insurance-claims  # Blog post
/guides/water-damage-cost            # Cost guide
```

### Sitemap Strategy

**Multiple Sitemaps (Organized by Type):**

**sitemap-index.xml** (Master sitemap)
```xml
<sitemap>
  <loc>https://disasterrecovery.com.au/sitemap-pages.xml</loc>
</sitemap>
<sitemap>
  <loc>https://disasterrecovery.com.au/sitemap-locations.xml</loc>
</sitemap>
<sitemap>
  <loc>https://disasterrecovery.com.au/sitemap-resources.xml</loc>
</sitemap>
```

**sitemap-pages.xml** (Core pages: 10-20 URLs)
- Homepage
- Service pages (/water-damage, /fire-restoration, etc.)
- About, Contact, Contractors pages

**sitemap-locations.xml** (Location pages: 5,000-10,000 URLs)
- All /[city]/[service] pages
- Split into multiple sitemaps if >50,000 URLs
- Priority: 0.7-0.9 (high importance)
- Changefreq: weekly

**sitemap-resources.xml** (Blog posts, guides: 100-500 URLs)
- All /resources/* pages
- All /guides/* pages
- Priority: 0.5-0.7
- Changefreq: monthly
