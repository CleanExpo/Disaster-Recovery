## Verification queries (post-#336 deploy)

```sql
-- Confirm ContractorPayment landed
SELECT table_name FROM information_schema.tables
WHERE table_schema = 'public' AND table_name = 'ContractorPayment';

-- Full phantom-vs-live reconciliation
SELECT m.model_name
FROM (VALUES
  ('User'), ('Enquiry'), ('Lead'), ('Partner'), ('PartnerBilling'),
  ('LeadTracking'), ('LeadNote'), ('Contractor'), ('ContractorApplication'),
  ('ContractorCompany'), ('ContractorInsurance'), ('ContractorSubscription'),
  ('ContractorPayment'), ('ContractorDocument'), ('ContractorTerritory'),
  ('ContractorKPI'), ('ProofOfWork'), ('CompetencyTestResult'),
  ('ContractorNotification'), ('ContractorAuditLog'), ('OnboardingPayment'),
  ('OnboardingProgress'), ('ModuleProgress'), ('ErrorLog'), ('AuditLog'),
  ('Job'), ('JobOffer'), ('JobOutcome'), ('BotConversation'),
  ('ServiceRequest'), ('ClientProfile'), ('ContractorProfile'),
  ('InspectionReport'), ('CostEstimate'), ('Booking'), ('InsuranceClaimAU'),
  ('Rating'), ('Payment'), ('RedditContentPillar'), ('RedditPost'),
  ('RedditSafetyAudit'), ('RedditPerformanceLog'), ('RedditOrchestratorRun'),
  ('RedditSystemPrompt'), ('PushToken'), ('ClaimPhotoAttachment'),
  ('ClaimNotification'), ('SubContractor'), ('SubContractorEngagement'),
  ('FinanceReferral'), ('FinanceReferralEvent'), ('VoiceCall'),
  ('CallTranscript'), ('WebhookDelivery')
) AS m(model_name)
LEFT JOIN information_schema.tables t
  ON t.table_schema = 'public'
 AND (t.table_name = m.model_name
   OR t.table_name = lower(regexp_replace(m.model_name, '([a-z])([A-Z])', '\1_\2', 'g')))
WHERE t.table_name IS NULL
ORDER BY m.model_name;
```

The second query returns the names of any models that still lack a
backing table. Expected result post-deploy: empty set, OR a small
list of @@map'd models (where the LEFT JOIN's snake_case fallback
misses the actual mapped name).
