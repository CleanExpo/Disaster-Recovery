## Executive Summary

DesignOS is the comprehensive design system powering the NRPG dual-sided SaaS platform. It provides a shared foundation with distinct brand expressions for:

1. **Disaster Recovery** (Client-Facing) - Calm authority for crisis situations
2. **NRPG** (Contractor-Facing) - Professional network for restoration experts

### Core Philosophy

**Not a brochure site.** An authority-driven emergency education and trust funnel.

**Design Principles:**
1. **Context-Aware Adaptation** - Emergency pages = minimal, calm. Education pages = enhanced, engaging.
2. **Authority Through Clarity** - Institutional trust via typography, clinical precision in content.
3. **Crisis-Optimized UX** - Zero friction for 2am panic users with shaking hands.
4. **Progressive Education** - Stop panic → Build understanding → Enable action.
5. **Shared Foundation, Distinct Expression** - Same component library, different brand skins.

## Strategic Decisions (From 16 In-Depth Interviews)

### Crisis Psychology & First Impression
**Decision:** Calm authority - "You're safe now, we've got this"
- Immediate reassurance over urgency creation
- Professional confidence reduces panic
- Expert presence calms stressed users

### Brand IP Strategy
**Decision:** Trademark "Who First?" - Own the authority positioning
- Register with IP Australia
- Use ™ symbol in all materials
- Build brand moat around phrase
- SEO dominate the question

### Visual Truth-Telling
**Decision:** Homepage prominence for before/after photos
- Show consequences upfront in "Why Quality Matters" section
- Expandable cards (user opts-in to view detail)
- Clinical annotations, not sensationalism
- Establish differentiation immediately

### Dual Brand Architecture
**Decision:** Shared foundation, different expressions
- Same components, spacing, typography
- Different color palettes per brand
- Disaster Recovery = blue/teal (calm)
- NRPG = navy/gold (professional)

### Crisis CTA Design
**Decision:** Dual CTAs - "Call Now" + "Get Help Online"
- Phone for true emergencies
- Online form for less urgent
- Reduces decision paralysis

### Decision Tree UI
**Decision:** Hybrid - Quick tree → Deep articles
- 3-4 questions to route
- Parallel layout (actions + diagnostic)
- Then comprehensive article

### Contractor Portal Paradigm
**Decision:** LinkedIn-style professional network
- Profiles, connections, growth focus
- Less transactional, more professional development
- Quality over volume

### Color Psychology
**Decision:** Dual palette - Context-aware switching
- Emergency pages = red/urgent
- Education pages = blue/teal calm
- Automatic based on URL path

### Validation Timing
**Decision:** Smart hybrid
- Format errors = instant on blur
- Required errors = on submit
- Balance immediacy with not overwhelming

### Process Education
**Decision:** All four formats
- Animated timeline (scroll reveals)
- Interactive checklist (track progress)
- Explainer video (60-90 sec)
- Accordion FAQ (scannable)

### Contractor Metrics
**Decision:** Show all three - earnings, completion rate, rating
- Financial success = social proof
- Equal prominence
- Transparency builds trust

### Loading States
**Decision:** Detailed step-by-step progress
- Show what's happening
- Manage expectations
- Reduces perceived wait

### Typography Authority
**Decision:** Large serif headlines (Playfair/Merriweather)
- Institutional trust signals
- Government/legal/medical associations
- Premium positioning

### Mobile CTA Pattern
**Decision:** Sticky bottom button (always visible)
- Easy thumb reach
- Never scroll away from CTA
- Full-width for panic users

### Before/After Presentation
**Decision:** Expandable cards
- Thumbnail view initially
- Click to see full comparison
- Opt-in for graphic content
- Respects user comfort level

### Locked Job UX
**Decision:** Silent lock (grayed out, no interaction)
- Visual only
- No explanation on click
- Minimizes frustration
- Clean UI

### Error Recovery
**Decision:** Transparent explanation with auto-action
- Explain what's happening
- Show system intelligence
- Provide alternatives
- Never dead-end user

### Motion Philosophy
**Decision:** Disable animations on emergency paths
- Crisis = zero animation
- Education = subtle enhancements
- Respect prefers-reduced-motion

### CRM Priority Signaling
**Decision:** ALL FOUR indicators
- Color coding
- Icon system
- Auto-position (top of list)
- Size/prominence

### System Documentation
**Decision:** Storybook + Figma
- Storybook for developers (live components)
- Figma for designers (source of truth)
- Both in sync
