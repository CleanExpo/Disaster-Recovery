Treatment Protocol Matrix

Fire/Smoke Odour Protocol

  1. HEPA vacuum all surfaces
  2. Wash with alkaline detergent
  3. Seal porous surfaces (Kilz/BIN)
  4. Thermal fog with OdorX Thermo-55
  5. Run hydroxyl generators 48-72 hours
  6. Final verification with photoionization detector

Pet/Urine Odour Protocol

  1. UV black light inspection
  2. Sub-surface extraction if needed
  3. Enzyme treatment injection
  4. Allow 24-hour dwell time
  5. Extract and rinse
  6. Apply oxidising agent if required

Mould Odour Protocol

  1. Complete mould remediation first
  2. HEPA vacuum all surfaces
  3. Apply antimicrobial (Microban)
  4. Hydroxyl treatment 24-48 hours
  5. Install carbon filtration if needed
  6. Post-remediation verification testing

Safety & Compliance

⚠ Australian Safety Requirements

  • Ozone Safety: Maximum 0.1 ppm exposure (SafeWork Australia)
  • Re-entry Time: Minimum 2 hours after ozone treatment
  • PPE Required: P2 respirator, safety glasses, gloves during fogging
  • Ventilation: Minimum 4 air changes per hour during treatment
  • Monitoring: Use PID or ozone meter before re-entry
  • Documentation: Treatment log, safety data sheets, customer advisory
